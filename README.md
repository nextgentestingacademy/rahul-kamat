# Rahul Abhay Kamat — Technology Educator & IT Visiting Faculty

Official personal academic and professional profile website for **Rahul Abhay Kamat**: Technology Educator, IT Visiting Faculty, and Enterprise Quality Engineering Leader.

## Purpose & Positioning

The primary objective of this website is to present Rahul's qualifications, university pedagogy, and corporate training engagements:

- **Visiting Faculty Opportunities**: Academic delivery for semester and module courses across colleges in Mumbai (M.Sc. IT, B.Sc. IT, Computer Science, Engineering).
- **University Pedagogy**:
  - *M.Sc. IT*: Data Structures and Algorithms (DSA) using Java
  - *F.Y. B.Sc. IT*: Art of Programming
  - *Modern AI Pedagogy*: Vibe Coding using AI (prompt-driven architecture, LLM pair programming, rapid prototyping)
- **Guest Lectures & Workshops**: Hands-on student sessions in test automation, API testing, and performance profiling.
- **Corporate Technical Training**: Custom upskilling programs for engineering teams and SDETs across global financial institutions.

## Technology Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Modern responsive CSS (Dark academic-technology theme)
- **Icons**: Lucide React
- **Deployment**: Vercel

## Local Development

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```

### 3. Production Build
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
